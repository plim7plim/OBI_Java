# OBI em Java — 4 dias

Consulte a [apostila de Java](treino/java.md) para aprender declarações, entrada e saída, laços, vetores, strings, métodos e coleções. Depois pratique com os [exercícios](treino/exercicios.md). Tente cada questão antes de abrir o gabarito.

| Dia | Faça | Meta |
|---|---|---|
| 1 | Recordes e Maior sequência | Ler a entrada e resolver cada questão em uma passada |
| 2 | Mediana e Frequências | Praticar ordenação, vetores e contagem |
| 3 | Somas de intervalos | Comparar uma solução direta com soma de prefixos |
| 4 | Maratona 2022: problemas I, A, J, E, D e F | Resolver problemas reais de prova, do mais fácil ao mais difícil |

Para o simulado, escolha um caderno em https://olimpiada.ic.unicamp.br/pratique/.

## Rodar localmente

Com um JDK no PATH, execute da raiz do repositório:

```powershell
"6`n-3 -3 -1 -2 0 0" | java solucoes/Recordes.java
```

O comando usa o modo de execução de arquivo-fonte do Java 11 ou superior. Cada solução é independente. Ao submeter na OBI, siga o nome de arquivo e de classe indicado no enunciado.

Depois de cada tentativa, anote a ideia, a complexidade e um caso que você esqueceu de testar.
