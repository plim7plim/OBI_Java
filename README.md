## Rodar localmente

Com um JDK no PATH, execute da raiz do repositório:

```powershell
"6`n-3 -3 -1 -2 0 0" | java solucoes/Recordes.java
```

O comando usa o modo de execução de arquivo-fonte do Java 11 ou superior. Cada solução é independente. Ao submeter na OBI, siga o nome de arquivo e de classe indicado no enunciado.

Depois de cada tentativa, anote a ideia, a complexidade e um caso que você esqueceu de testar.
